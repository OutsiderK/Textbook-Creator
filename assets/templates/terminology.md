# Terminology

> 跨章节统一的术语对照。写章节遇分歧以本表为准。
> 仅记录有"分歧"或"翻译多版本"的术语；显然且无歧义的术语不必列。

## 推荐用法 vs 不推荐

| 推荐 | 不推荐 / 仅初次说明可附 | 备注 |
|---|---|---|
| 系统调用 | 系统呼叫 | 大陆教材统一用"系统调用" |
| 内核态 | 核心态 / 管理态 | 首次出现可附"亦称核心态/管理态"，后文一律内核态 |
| 饥饿 | 饿死 | "饿死"过于口语 |
| 页框 | 页面框 / 物理页 | 用"页框"指物理内存中的存储单元 |
| 虚拟页 | 逻辑页 / 页面 | 用"虚拟页"指虚拟地址空间的页 |

## 英文术语首次出现

格式：`**中文术语（English term）** 一句话解释。`

- 同一术语在书中**只在首次出现时**给英文。
- 后续章节直接用中文。
- 若英文有缩写（如 TLB、MMU），首次写"**翻译缓冲器（Translation Lookaside Buffer, TLB）**"，之后用 TLB。

## 同义但用法分场景的术语

- **进程切换** vs **上下文切换**：进程切换是更宽的概念（含调度决策），上下文切换专指 PCB/寄存器的保存恢复。
- **线程** vs **轻量级进程**：在 Linux 语境下两者等价；理论章节区分用户级/内核级线程时用"线程"。
